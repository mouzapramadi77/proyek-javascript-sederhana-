# Proyek JavaScript Sederhana

🔗 Tautan Repositori: https://github.com/mouzapramadi77/proyek-javascript-sederhana

📜 Lisensi: MIT

## Tentang Proyek
Proyek ini berisi contoh kode JavaScript dasar untuk pemula.

## Isi Repositori
- `index.html` → Halaman tampilan utama
- `script.js` → Kode logika JavaScript
- `.gitignore` → Mengabaikan berkas yang tidak perlu dikirim

## Cara Menggunakan
1. Unduh atau klon repositori
2. Buka `index.html` di peramban web
3. Klik tombol untuk melihat hasil kerja JavaScript

## Fitur
- ✅ Menampilkan pesan saat tombol diklik
- ✅ Menghitung angka dari 1 sampai 10
- ✅ Pesan muncul di konsol peramban
